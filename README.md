# いろどりパレット

色をひとつ選ぶだけで、調和する5色の配色パレットを自動生成する無料Webアプリ(PWA)。
**アプリ本体: https://gryo1240.github.io/irodori/**

- **配色を自動生成**: ベース色×配色タイプ(おまかせ/類似色/補色/トライアド/濃淡/パステル/くすみ)で色彩理論に沿った5色を生成。タップでHEXコピー、CSS変数コピー、PNG画像保存、共有リンク発行
- **見本帳**: 気分で選べるキュレーションパレット16種(ふんわりパステル/和モダン/レトロポップなど)+和の伝統色48色(読み仮名・カラーコード付き)
- **プレビュー&見やすさ判定**: 生成した配色をサイト風モックに自動適用。文字×背景のコントラスト比をWCAG基準(AA=4.5:1)で自動判定
- **保存**: 気に入った配色を端末内(localStorage)に保存。外部送信なし
- **リライト不要の設計**: 色彩理論・コントラスト計算・伝統色という不変の知識だけで構成。変わりうる情報(商品・料金・流行語)は持たない

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体(HTML/CSS/JSすべて1ファイル。見本帳データ`PRESETS`/`WACOLORS`を内蔵) |
| `manifest.webmanifest` / `sw.js` | PWA化(インストール・オフライン対応) |
| `icon-*.png` / `apple-touch-icon.png` | アプリアイコン(紫地に絵の具パレット) |
| `docs/screenshot-*.png` | 紹介用スクリーンショット |

`main` ブランチに push すると GitHub Pages に自動デプロイされます。

URLパラメータ `?t=book`(見本帳) `?t=wa`(和の伝統色) で開くタブを指定でき、`#c=RRGGBB,...×5` でパレットを直接共有できます。

ブログ等での紹介記事を書く場合は [HANDOVER.md](HANDOVER.md) を参照してください。
